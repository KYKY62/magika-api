Magika API

REST API web service for AI-powered file type detection. Upload files, send bytes, or provide URLs — get precise content-type identification in milliseconds.

📡 API Endpoints

POST /api/detect/file

Upload one or more files via multipart/form-data for detection.

cURL Example
# Single file
curl -X POST http://localhost:3000/api/detect/file \
  -F "file=@photo.jpg"

# Multiple files
curl -X POST http://localhost:3000/api/detect/file \
  -F "file=@photo.jpg" \
  -F "file=@document.pdf"
Response
{
  "success": true,
  "count": 1,
  "results": [{
    "fileName": "photo.jpg",
    "fileSize": 204800,
    "detection": {
      "label": "jpeg",
      "mime_type": "image/jpeg",
      "group": "image",
      "description": "JPEG image",
      "score": 0.99
    }
  }]
}
POST /api/detect/bytes

Send file content as base64-encoded JSON for detection.

cURL Example
curl -X POST http://localhost:3000/api/detect/bytes \
  -H "Content-Type: application/json" \
  -d '{"bytes":"IyBIZWxsbyBXb3JsZA==","fileName":"readme.md"}'
Response
{
  "success": true,
  "fileName": "readme.md",
  "fileSize": 13,
  "detection": {
    "label": "markdown",
    "mime_type": "text/markdown",
    "group": "text",
    "description": "Markdown document",
    "score": 0.95
  }
}
POST /api/detect/url

Provide a URL — the server fetches and detects the file type for you.

cURL Example
curl -X POST http://localhost:3000/api/detect/url \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/image.png"}'
GET /api/health

Health check endpoint — returns service status and uptime.

cURL Example
curl http://localhost:3000/api/health
